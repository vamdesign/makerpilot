# App image assets

All raster/SVG image files used by the demo live here.

| Path | Used for |
|------|----------|
| `base-gradient.png` | Header sky gradient (`CloudSkyHeaderBand`, `ScreenBackground`) |
| `generic-item.png` | Manual item placeholder thumbnail |
| `welcome-bkg.svg` | Welcome screen background |
| `maker-logo.svg` | Welcome / sign-in logo |
| `logos/` | Etsy, Shopify, Wix, Square sync logos |
| `products/` | Inventory listing product thumbnails |
| `icons/` | Business-type channel icons (pp01–pp04) |
| `svg/` | SVG path data for sign-in/sign-up decor and paper-plane icon |

Small React wrappers live in `src/app/components/icons/` — they import from here.
